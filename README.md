# 旅行照片整理器 DEMO

這是給「旅行照片整理器」看的**可點示範頁**，不是正式產品。

- 行程、照片、花費、心得都是**範例資料**（2026 東京＋京都 5 天）
- 資料只存在瀏覽器的 localStorage，沒有後端，也不會讀你手機裡的相簿
- 地圖使用 OpenStreetMap（免費、不用金鑰）
- 花費數字示範串接「旅伴帳」，皆標明為範例

線上示範：https://qa29173687-ship-it.github.io/travel-photo-demo/

## 畫面

- **匯入照片**：模擬讀取每張照片的時間與 GPS，再依日期、地點自動分組
- **時間軸**：Day 1–5，地點如淺草寺、澀谷、伏見稻荷；沒有 GPS 的照片在「未定位」，可指定地點
- **地圖**：圖針、每天路線、可依天數篩選，點圖針看照片
- **每天心得**：可改，存在這個瀏覽器
- **分享旅伴**：示範邀請連結（不會真的把朋友加進來）
- **旅伴帳花費**：每天顯示範例金額
- **相簿旅遊書**：封面、總覽地圖、每天照片與心得

正式 App 會在手機上直接讀取照片的 EXIF 時間與位置，不必上傳到雲端。
